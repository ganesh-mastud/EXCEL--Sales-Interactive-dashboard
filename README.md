📊 Sales Dashboard – Excel

📌 Project Overview

This project is an interactive Sales Dashboard created in Microsoft Excel to analyze and visualize sales performance.
The dashboard provides insights into sales, profit, products, customers, regions, sales representatives, and payment methods using interactive Excel features.

📈 Dashboard Features

•	Total Sales and Profit analysis
•	Units Sold analysis
•	Sales by Region and City
•	Product Category and Product performance
•	Sales Representative performance
•	Customer-wise sales analysis
•	Payment Method analysis
•	Interactive filters and dashboard controls
•	Charts and visualizations for quick insights

🛠️ Tools & Technologies

•	Microsoft Excel
•	Excel VBA / Macros
•	Pivot Tables & Charts
•	Excel Formulas
•	Data Analysis & Visualization

▶️ How to Use

1.	Download the complete repository.
2.	Keep Sales_Dashboard.xlsm and Sales_Data.xlsx in the same folder.
3.	Open Sales_Dashboard.xlsm using Microsoft Excel Desktop.
4.	If Excel displays a security warning, click Enable Content / Enable Macros.
5.	Use the available filters and interactive controls to explore the dashboard.

🎯 Project Objective

The objective of this project is to transform raw sales data into an interactive and easy-to-understand business dashboard that helps users analyze sales performance and identify useful business insights.
